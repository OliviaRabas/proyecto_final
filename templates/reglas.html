📋 Reglas

  1. Elegí un continente, o Global para jugar con todos.
  2. Va a aparecer una bandera y cuatro nombres de países.
  3. Movete entre las respuestas con las flechas y confirmá con Enter.
  4. Tenés 60 segundos. Cada acierto suma 1 punto.
  5. Las banderas no se repiten: el juego termina cuando se acaba el tiempo o cuando pasaron todas.

Atajos: Q = arriba izquierda, W = arriba derecha, A = abajo izquierda, S = abajo derecha. Con Esc volvés para atrás.
